# Encode & Decode Strings - Array and String Manipulation

## Intuition

### Encode method

- Use a delimeter, like `#`, to seperate each word.
- Append the length of each word as a string to the start of the word
- Create a long string that holds the concatenation of the above, for every string in `strs`

### Decode method

- Take in the long string generated by the `encode` method
- Create a `[]` to hold the list of decoded strings, `i` and `j` will be indeces
- Increase `j` count until a `#` is reached.
- `length` will hold the `int` value of each decoded word in the long string
- `[]` will be appended with current decoded word
- Update your pointers

## Algorithm

### Decoding

1. `res` will be an empty array `[]` and `i = 0` will be used as a pointer.
2. Begin a while condition for `i` being less than `len(s)`
3. Initialize `j = i` to mirror the `i` pointer and move `j` forward until it reaches the `#` character. W
4. Convert the substring `s[i:j]` into an integer `length`
5. Slice the `s` from `j + 1` up until `j + 1 + length`, this is the actual word. Append this word to the `res` array
6. Update `i` to be the end of this appended word, i.e, `i = j + 1 + length`
7. Return `res`

## Time and Space Complexity

- Time complexity: `O(m)` for each `encode()` and `decode()` funciton calls
- Space complexity: `O(m+n)` for each `encode()` and `decode()` function calls

## Implementation

### Python

```python
class Solution:

    def encode(self, strs: List[str]) -> str:

        resultString = ""
        for s in strs:
            resultString += str(len(s)) + "#" + s
        return resultString

    def decode(self, s: str) -> List[str]:

        res, i = [], 0

        j = 1
        while i < len(s):
            j = i
            while s[j] != '#':
                j += 1
            length = int(s[i:j])
            res.append(s[j + 1 : j + 1 + length])
            i = j + 1 + length
        return res
```

### Java

```java
class Solution {

    // Encodes a list of strings to a single string.
    public String encode(List<String> strs) {
        StringBuilder res = new StringBuilder();
        for (String s : strs){
            res.append(s.length()).append('#').append(s);
        }
        return res.toString();
    }

    // Decodes a single string to a list of strings.
    public List<String> decode(String s) {
        List<String> res = new ArrayList<>();
        int i = 0;
        while (i < s.length()){
            int j = i;
            while (s.charAt(j) != '#'){
                j++;
            }
            int length = Integer.parseInt(s.substring(i,j));
            i = j + 1;
            j = i + length;
            res.add(s.substring(i, j));
            i = j;
        }
        return res;
    }
}
```
